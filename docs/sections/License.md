# License

## Licensing Process

Commercial users must contact [raisim@raionrobotics.com](mailto:raisim@raionrobotics.com) to obtain a commercial client ID before following the instructions below.

An **activation key** is required to operate RaiSim.
Activation keys may be requested via the **RaiSim License Request Form**:

  </a>
</p>

After the request is submitted and reviewed, an activation key is issued.

The Activation Key section of [Installation](./Installation.md) explains where to place the
key, and the included examples show how to load it.
For licensing inquiries, please contact [raisim@raionrobotics.com](mailto:raisim@raionrobotics.com).

Available license types:

- Commercial License ([SLA](https://drive.google.com/file/d/1IAHbS8mXTCyVAnMikp3WyT0cCqFCxTZw/view?usp=sharing)): 1500 USD per person per year.
- Academic License ([SLA](https://drive.google.com/file/d/10W_9H8Ur37B6GllR0Qb3JQyj7Fh-AVlx/view?usp=sharing)): Free of charge.
- Trial License ([SLA](https://drive.google.com/file/d/1-fUZx2_h9UO3KcePWRjRz-itiypHORp2/view?usp=sharing)): Free of charge, valid for one month.

Purchases of three or more commercial licenses include a master key valid for use on any machine.
